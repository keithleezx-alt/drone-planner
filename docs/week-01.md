# Week 1 — Environment & Command Line

**Milestone:** From a fresh terminal, create a directory, write a script, and run
it inside a virtual environment — no GUI.

## Branch
`week-1-setup`

## Tasks
- [x] Get to a working Ubuntu terminal (native, dual-boot, or VM).
- [x] Practice: `cd`, `ls`, `pwd`, `mkdir`, `mv`, `cp`, `rm`.
- [x] Create a virtual environment and activate it (`python3 -m venv .venv`).
- [x] `pip install -r requirements.txt`.
- [x] Edit `src/hello.py` to print your name and today's date; run it from the CLI.

## Deliverable / PR
Open a PR titled **"Week 1: setup"** with your `hello.py` change and a screenshot
of it running in the terminal.
